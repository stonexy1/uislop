# Security policy

**English** · [Русский](#политика-безопасности)

`slopscan` reads files from disk and writes only when you ask it to (`--badge`, `init`). It makes no network
requests and runs no code from the scanned project.

To report a vulnerability, use [GitHub private vulnerability reporting](https://github.com/stonexy1/uislop/security/advisories/new).
Do not open a public issue. You will get a reply within 7 days. Fixes are released for the latest minor version.

## Политика безопасности

[English](#security-policy) · **Русский**

`slopscan` читает файлы с диска и пишет только по вашей команде (`--badge`, `init`). Он не делает сетевых запросов и
не выполняет код из сканируемого проекта.

Об уязвимости сообщайте через [закрытый отчёт GitHub](https://github.com/stonexy1/uislop/security/advisories/new),
не через публичный issue. Ответ придёт в течение 7 дней. Исправления выпускаются для последней минорной версии.
